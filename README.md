# Neuroscience Research Portfolio

A GitHub Pages-ready personal research portfolio focused on molecular neuroscience, neurodevelopment, behavioral neuroscience, and neuropsychiatry.

## Publish with GitHub Pages

1. Create a repository named `YOURUSERNAME.github.io` (or any repository you prefer).
2. Upload the contents of this folder, keeping the directory structure intact.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
5. Save. GitHub Pages will publish the site.

## Main files

- `index.html` — homepage
- `assets/style.css` — site styling
- `assets/script.js` — interactions
- `projects/` — space for individual project pages
- `cv/` — space for a CV PDF
- `assets/` — images and other site assets

Replace the placeholder name/contact details in `index.html` before publishing.
